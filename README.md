# Supermarket Management System

**Ứng dụng quản lý hệ thống siêu thị toàn diện**

## 🎯 Chức năng chính

- ✅ Quản lý sản phẩm (CRUD)
- ✅ Quản lý kho hàng & tồn kho
- ✅ Quản lý bán hàng & đơn hàng
- ✅ Quản lý nhân viên
- ✅ Báo cáo doanh thu & thống kê
- ✅ Hệ thống người dùng & phân quyền

## 📋 Công nghệ sử dụng

- **Frontend**: React.js + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## 📁 Cấu trúc dự án

```
supermarket/
├── frontend/          # React application
├── backend/           # Express API server
├── docs/              # Documentation
└── README.md
```

## 🚀 Hướng dẫn cài đặt

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```
